# KBMacro 便携键鼠自动化小工具 - 设计文档

> 版本：MVP-3.3  
> 许可：GPL-v3  
> 平台：Windows x64（仅支持 Windows 10 / 11）  
> 开发环境：Visual Studio 2022+ / CMake 3.25+ / Conan 2 / Ninja

---

## 1. 项目概述

KBMacro 是一款轻量便携的 Windows 键鼠自动化工具，单 EXE 免安装，U 盘即拷即用。

### 三大核心功能

- **鼠标连点器**：支持坐标/当前位置、多种按键、滚轮、侧键
- **键盘模拟器**：支持组合键、单次/重复发送
- **键鼠录制与回放**：支持分辨率/DPI 适配

### 设计原则

- 所有基础设施（线程、队列、日志、JSON）使用成熟库，不自行造轮子
- 所有代码在同一项目中，不拆分子模块，减少心智负担
- 日志和测试代码通过 CMake 选项控制开关，与构建类型解耦
- 静态链接，输出单一 EXE，无需任何 DLL

## 3. 功能需求

### 3.1 鼠标连点器

- 坐标设置：X/Y 输入框 + 捕捉坐标按钮（获取当前光标位置）
- 忽略坐标：勾选后点击当前光标位置，忽略 X/Y 设定
- 点击类型：左键、右键、中键、双击、滚轮（上/下/左/右）、侧键1/侧键2
- 滚轮步数：1–10 步
- 点击间隔：10–60000 ms
- 按住时间：5–200 ms（滚轮无此参数）
- 运行模式：无限循环 / 定时运行（秒） / 固定次数（1–999999）
- 参数导入导出：支持 `*.clicker.json` 文件

### 3.2 键盘模拟器

- 按键设定：通过热键捕获对话框设置，支持 Ctrl/Shift/Alt/Win 组合键
- 操作：发送一次、开始重复发送、停止重复
- 重复间隔：10–60000 ms
- 按键保持时间：5–200 ms
- 运行模式：无限循环 / 定时运行 / 固定次数
- 参数导入导出：支持 `*.keyboard.json` 文件

### 3.3 录制与回放

- 录制：使用低级键盘/鼠标钩子（WH_KEYBOARD_LL / WH_MOUSE_LL）捕获鼠标移动、点击、滚轮、键盘按下/抬起
- 记录信息：动作类型、坐标、按键代码、延迟时间（delayMs）、按住时间（holdMs）、滚轮步数、屏幕分辨率及 DPI
- 动作编辑：列表显示所有动作，支持编辑、删除、上移、下移、修改延时/保持时间/滚轮步数
- 回放模式：无限循环 / 定时回放 / 固定次数
- 坐标适配：回放时自动检测当前屏幕分辨率/DPI 变化，弹窗询问是否适配坐标（支持会话内记住选择）
- 脚本导入导出：支持 `*.macro.json` 文件

### 3.4 设置

- 语言切换：支持 zh-CN / en-US，需重启生效
- 配置管理：便携模式（EXE 同目录 `{exe}.json` 优先），否则使用 `%APPDATA%\KBMacro\config.json`
- 热键配置：列表展示 + 修改按钮（热键捕获对话框）
- 计时器模式：普通 Sleep / 高精度 Spin（下拉选择，切换时弹窗提醒 CPU 占用）
- 窗口置顶：复选框，立即生效
- 重置功能：清除适配记忆 / 清除高精度确认 / 恢复默认设置

### 3.5 关于与许可

- 显示程序信息、版本、项目链接
- 完整 GPL-3.0 及第三方库许可证（从资源加载）

## 4. 依赖与构建

所有依赖通过 Conan 2 管理，强制静态链接。

### Conan 依赖列表

- wxwidgets（3.2.11）
- nlohmann_json（3.12.0）
- spdlog（1.17.0）
- gtest（1.15.0）
- wil（1.0.260126.7）
- concurrentqueue（1.0.5）

### 构建要求

- 编译器：MSVC（Visual Studio 2022+）支持 C++20
- 构建工具：CMake 3.25+、Ninja
- 所有依赖库静态链接，运行时库使用 `/MT`（Release）

### CMake 选项

- `ENABLE_LOGGING`：开启日志支持（默认 OFF，可手动开启）
- `ENABLE_TESTS`：开启单元测试（默认 OFF，可手动开启）

## 5. 项目结构（概要）

```text
KBMacro/
├── CMakeLists.txt
├── conanfile.txt
├── CMakePresets.json
├── res/                # 资源文件（图标、版本信息、许可证、语言文件）
├── src/
│   ├── common/         # 通用定义（常量、枚举、类型）
│   ├── ui/             # wxWidgets 界面类（主窗口、各功能面板、设置面板、关于）
│   ├── modules/        # 业务逻辑模块（连点器、键盘模拟器、宏引擎）
│   ├── managers/       # 管理类（配置、热键、语言）
│   └── win32/          # Win32 API 薄封装（输入模拟）
├── tests/              # 单元测试（核心逻辑）
└── logs/               # 运行时日志（由 ENABLE_LOGGING 控制）
```

## 6. 测试范围

- **P0**：动作序列化/反序列化、坐标适配计算
- **P1**：配置读写（含便携模式路径）、运行模式逻辑（无限/定时/固定次数）
- **不测试**：UI、钩子回调、WIL、SendInput
- 测试通过 CMake 选项 `ENABLE_TESTS` 控制，默认关闭

---

## 8. 重要约束

- 钩子回调必须极速返回，只做入队，禁止日志或锁
- 模拟输入结构体必须清零
- 后台线程禁止直接操作 UI 控件，须通过 `wxQueueEvent` 或 `CallAfter`
- 日志代码通过 `ENABLE_LOGGING` 选项控制，默认关闭
- 所有动态库均静态链接，最终仅生成一个 EXE
- 测试代码通过 `ENABLE_TESTS` 选项控制，默认关闭
